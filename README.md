# PD Connect

**A full-stack application developed for Evergreen Commons' Parkinson's disease program as part of Hope College's SHARP summer research program.**

## Overview

PD Connect was developed to centralize resources, simplify data management, make information more accessible and understandable, and make it easy for staff and members of Evergreen Commons' Parkinson's disease program to export health assessment history to their healthcare providers.

The application was designed with accessibility and usability in mind, particularly for individuals living with Parkinson's disease.

## Tech Stack

- **Frontend:** Flutter, Dart
- **Backend:** Java, Spring Boot
- **Database:** PostgreSQL
- **Authentication:** AWS Cognito
- **Cloud Infrastructure:** AWS ECS, RDS, ALB
- **Database Migrations:** Liquibase

## Key Features

- Centralized access to program resources
- Symptom tracking functionality
- Data export capabilities using CSV and PDF
- User authentication and account management
- Accessible interface with larger text and intuitive navigation
